Interacción

Pseudoclases que responden a la interacción directa del usuario con la página.

:active

Se aplica mientras un elemento está siendo activado por el usuario, por ejemplo al pulsar un botón.

:focus

Se aplica a un elemento que tiene el foco, como un campo seleccionado o un enlace alcanzado con el teclado.

:hover

Se aplica cuando el puntero del ratón se sitúa sobre un elemento.

Pasa el cursor por aquí

Formularios

Pseudoclases relacionadas con el estado y la validación de los controles de formulario.

:checked

Se aplica a controles de formulario marcados, como casillas de verificación o botones de opción.

:default

Se aplica al control de formulario que se considera predeterminado dentro de un grupo.

:disabled

Se aplica a controles de formulario deshabilitados, que no pueden usarse ni recibir foco.

:enabled

Se aplica a controles de formulario habilitados y disponibles para la interacción.

:indeterminate

Se aplica a controles cuyo estado es indeterminado, como una casilla con estado mixto.

:in-range

Se aplica a controles cuyo valor se encuentra dentro del rango permitido.

:invalid

Se aplica a controles cuyo valor no cumple las reglas de validación.

:optional

Se aplica a controles de formulario que no son obligatorios.

:out-of-range

Se aplica a controles cuyo valor se encuentra fuera del rango permitido.

:read-only

Se aplica a elementos que el usuario no puede modificar.

:read-write

Se aplica a elementos editables por el usuario.

:required

Se aplica a controles de formulario que son obligatorios.

:valid

Se aplica a controles cuyo valor cumple las reglas de validación.
